# 阶段 6 实施进度：数据库绑定与兼容增强

## 6.1 基线审计与数据库绑定契约（已完成）

### 已核对的现状

- 环境级数据库工作台使用 `DatabaseConnection`，按 `EndpointID` 与创建者隔离；已有 MySQL、MariaDB、PostgreSQL、Redis 的直连查询能力。
- 工作台的真实访问始终使用 `Host` 与 `Port`。`ContainerID` 仅保留为容器来源的展示、自动填充和旧数据兼容字段，不能成为平台绑定或发布访问的依赖。
- 平台 ConfigSet 已能将敏感值加密为密文，并在 Release 中保存不含明文的 `SecretSnapshots`。但个人 `DatabaseConnection` 不能直接作为项目共享部署资源，否则会让其他项目成员间接使用或获得创建者的私有密码。
- 当前对象存储实现只有 S3 Compatible adapter；PRD 将阿里云 OSS 定义为兼容验证项，不是 V0.5 Gate。尚无真实目标 OSS 凭据和演练结果，不能宣称兼容通过，也不能擅自引入厂商 SDK。

### 冻结的数据库资源边界

| 对象 | 归属与用途 | 密文边界 |
| --- | --- | --- |
| `DatabaseConnection` | 用户在某个 Endpoint 下的个人数据库工作台连接 | 保持原有隔离；不直接用于项目部署绑定 |
| 平台数据库资源 | 归属一个项目、环境与 Endpoint，可被有项目权限且有 Endpoint 权限的成员使用 | 密码只保存为平台受控密文，API、审计、导出与普通 Release 快照均不返回明文 |
| 服务部署数据库绑定 | 归属一个 ServiceDeployment，引用同项目、同环境、同 Endpoint 的活跃平台数据库资源 | 仅保存资源 ID、变量映射和版本；不复制密码 |
| 运行期数据库变量 | 在发布预检和 Docker runtime 配置构造期间短暂解析 | 使用后不得写入 Release、审计、日志或响应 |

### 支持矩阵与变量规则

- 支持类型限定为 MySQL、MariaDB、PostgreSQL、Redis；本阶段不创建实例、不执行迁移、不管理数据库账号。
- 每个绑定固定生成：`DATABASE_HOST`、`DATABASE_PORT`、`DATABASE_USER`、`DATABASE_PASSWORD`、`DATABASE_NAME`、`DATABASE_URL`。
- MySQL/MariaDB URL 使用 `mysql://user:password@host:port/database`；PostgreSQL 使用 `postgres://user:password@host:port/database`；Redis 使用 `redis://[:password@]host:port[/database]`。完整 URL 与密码同为敏感运行期数据。
- 数据库绑定在 ConfigSet 合并之后参与发布解析。普通配置不得覆盖 `DATABASE_PASSWORD` 或写入含密码的 `DATABASE_URL`；若发生冲突，发布在切流前以稳定 reason 失败并保留当前 Release。
- 绑定变更只标记部署配置漂移，不自动重启服务。删除或归档被活跃绑定、进行中发布或历史快照引用的资源必须被阻止。

### 旧数据兼容与安全策略

- 不迁移、复制或共享既有 `DatabaseConnection.Password`；旧个人连接继续供原工作台使用。
- 只有通过平台数据库资源 API 新建或明确导入的连接，才可用于发布。导入时由具备项目及 Endpoint 权限的用户重新提交密码并立即加密；缺少加密服务时拒绝保存。
- 数据库连通性测试、OSS 操作和容量探测均在 handler 事务外执行；事务只用于写入受控结果、审计摘要和状态。

## 6.2 项目数据库资源与绑定模型（已完成）

- 新增 `PlatformDatabaseResource`：关联项目、环境和 Endpoint，保存类型、Host、Port、库名、用户名、超时、版本及加密密码元数据；模型校验拒绝明文密码。
- 新增 `PlatformServiceDatabaseBinding`：关联服务部署与数据库资源，只保存无密文引用及版本。
- 新增独立 BoltDB dataservice 与备份/导入支持；导出时强制移除数据库密码、密文、密钥版本和哈希，导入后必须重新填写凭据。
- 新增 `PlatformDatabaseBindingSnapshot`，为后续 Release 保存无密码的资源/绑定版本与变量哈希事实。
- 已覆盖资源创建、版本变更、绑定创建以及导出/导入后的凭据剥离。

## 6.3 绑定、预检与工作台关联 API（已完成）

- 新增项目数据库资源的列表、创建、读取、更新、归档和连通性测试接口；所有响应剥离密码密文、加密版本和哈希。
- 新增服务部署数据库绑定的列表、创建、更新、归档接口，以及仅含授权元数据的数据库工作台关联上下文接口。
- 资源和绑定操作同时校验项目角色、环境归属和 Endpoint 访问权限；跨项目、跨环境或不属于环境工作负载目标的资源无法绑定。
- 连接测试在 BoltDB 写事务外执行，返回 `DATABASE_UNREACHABLE` / `DATABASE_TIMEOUT` 等稳定 reason；审计不保留驱动原始错误或密码。
- 活跃绑定会阻止资源归档；绑定变更只标记部署配置漂移，不自动重启服务。
- 已覆盖密码不回显、密文持久化、工作台上下文、连通性稳定失败原因及引用保护。

## 6.4 发布变量解析与安全注入（已完成）

- Release 创建和验证会先构建数据库绑定的无密文快照，并在事务外完成短时数据库认证预检；失败以 `DATABASE_*` 稳定 reason 阻止切流。
- 快照只保存绑定/资源 ID、版本、类型与变量哈希；密码、完整 URL 和数据库密文不会进入 Release、审计或 API 响应。
- Docker runtime 在创建候选容器前重新读取活跃资源、校验版本与变量哈希、短时解密密码，再注入固定六个变量：`DATABASE_HOST`、`DATABASE_PORT`、`DATABASE_USER`、`DATABASE_PASSWORD`、`DATABASE_NAME`、`DATABASE_URL`。
- 资源在 Release 排队后被修改、归档或无法解密时，运行期会在候选容器启动前失败；历史 Release 快照也会阻止资源归档，并在回滚前校验资源版本。
- 普通 ConfigSet 和 EnvOverrides 不得占用六个数据库变量名，避免明文伪造密码或与绑定变量产生歧义。
- 已覆盖 PostgreSQL 变量生成、Release 快照无密码/无 URL、资源版本变化阻断运行期注入、发布预检与历史引用保护。
