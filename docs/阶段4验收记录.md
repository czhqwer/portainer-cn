## 已验证的后端能力

- 网关仅由平台以固定 `nginx:1.27-alpine` 镜像、固定标签和服务端生成的容器名创建；配置根目录与证书根目录均以只读方式挂载。
- 证书/私钥先由 Go TLS/X.509 校验，私钥写入受控本地目录；BoltDB、审计摘要、导出数据和 API 响应均不保存 PEM 私钥或真实材料路径。
- 域名/路径/端口/证书归属、TLS 组合、路由冲突、角色及 Endpoint 权限均在服务端校验。
- Nginx 配置由受控模型渲染为完整候选文件，按“候选写入 → `nginx -t -c` → 原子激活 → reload”执行；reload 失败会恢复上一个配置并再次 reload。
- 单目标 Release 在正式运行时健康检查通过后才调用网关切流；切流失败时 Release 进入失败恢复路径，避免标记为成功。
