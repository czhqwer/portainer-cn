# 阶段 5 验收记录：多 Docker 主机与分批发布

验收日期：2026-07-12  
阶段分支：`codex/platform-phase5`  
开发基线：`codex/platform-backend-base`（不向用户正在开发的 `develop` 合并）

## 已验证能力

- 平台专用 HostGroup 管理 workload 成员；环境 `multi` 模式强制至少一个 workload、恰好一个 gateway、唯一 Endpoint 与有效 HostAddress。
- Release 保存不可变 target 与 batch snapshot，逐主机写入 `TargetResults`；未执行目标在失败后显式标记为 `skipped`。
- 多目标执行按 batch 顺序运行，支持可取消批间等待；失败后暂停后续批，并恢复已成功 target。
- 网关容器以固定参数预检 `HostAddress:publishedPort`；预检结果仅返回 Endpoint ID 与稳定 reason。
- 仅成功 TargetResults 生成 Nginx 多 upstream；切流仍遵循候选配置、预检、原子激活、reload 与恢复。

## 待真实环境演练

本地未连接一个 gateway 与至少两个 Docker/Agent workload target，以下场景必须在真实环境补做：

1. gateway 到两台 workload `HostAddress:publishedPort` 的可达、不可达和端口冲突预检。
2. 第一批失败、第二批失败、批间取消、每种 target 恢复失败与人工重试。
3. 两台成功 target 的 Nginx upstream、部分失败 target 排除、reload 失败恢复与历史 Release 回滚。
4. Endpoint 权限变化、Agent 离线、进程重启时 running target 的 lease 恢复与审计证据。
