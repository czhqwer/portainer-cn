## 浏览器与真实运行环境演练

当前工作区未发现监听 `8999` 或 `9000` 的本地前后端服务，且没有可用的真实 Docker/Agent、生产 Endpoint 或多用户浏览器会话。因此以下项目已保留为部署环境手工演练项，不以模拟数据或绕过权限的方式替代：

1. 管理员在项目级、环境级、服务部署级分别创建普通与敏感配置，确认普通配置合并顺序为项目级 < 环境级 < 服务部署级 EnvOverrides。
2. 管理员确认 reveal/copy 二次确认、审计记录和浏览器剪贴板行为；开发者、观察者及无 Endpoint 权限用户确认入口隐藏/禁用且直接 API 仍被拒绝。
3. 在深色、浅色和高对比主题检查配置表单、有效配置表、审计表和回滚差异面板无溢出、重叠或敏感值泄漏。
4. 发布 v1、发布 v2、从发布记录预览并回滚 v1；再模拟镜像拉取失败或端口冲突，确认 v2 继续服务且回滚 Release 留有失败审计。
5. 在生产环境确认回滚差异预览后出现二次确认，取消时不创建 Release。

这些手工项不扩大阶段 2 范围；仅验证既有单机 Docker 发布链路与服务端权限边界。
