## 已冻结实施契约

### 7C 可观测性

- 只接入既有 Prometheus、Loki、Grafana，不部署组件、不代理任意 Dashboard。
- 管理员管理外部地址及加密认证信息；项目成员只能使用受白名单限制的只读查询模板。
- 每次查询最长 30 秒，严格限制时间范围、行数和序列数；原始上游错误不返回浏览器。
- 所有查询都要求项目权限与目标 Endpoint 权限交集。

### 7A 最小 HTTP 灰度

- 仅支持中心 Nginx、HTTP 服务、两个版本并存和单网关。
- 权重只能使用 0、5、25、50、100；由有权限用户显式执行，禁止自动放量。
- 每步放量前必须通过候选健康检查；失败时将新版本权重置为 0 并保持旧版本流量。
- 未接入指标自动判定前，不按错误率或请求量自动决策放量。
